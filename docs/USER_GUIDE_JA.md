# EMACS_OBSIDIAN 日本語ユーザーガイド

このガイドでは、ターミナル版 Emacs (`emacs -nw`) および GUI 版 Emacs で EMACS_OBSIDIAN を使いこなす方法（マウス操作、ビジュアル階層ツリー、Live Preview 編集、罫線／点字グラフビュー、デイリーノート、Git同期）を説明します。

## 1. EMACS_OBSIDIAN とは

EMACS_OBSIDIAN は、Markdown ファイルを Obsidian のように相互リンク・可視化しながら Emacs 内で快適に扱うパッケージです。`M-x obsidian` を実行すると、画面が3つの領域に分かれます。

```text
┌──────────────────────┬────────────────────────────────┬──────────────────────────┐
│ ▾ demo-vault [+新規] │ ▸ music/guitar [+新規][今日].. │ ◆ music [範囲][線:罫線]  │
├──────────────────────┼────────────────────────────────┼──────────────────────────┤
│   ▾ music/  8        │ # guitar                       │   ● piano     ● acoustic │
│   ├─ • acoustic      │                                │   ╰──╮        ┏━━┛       │
│ ▎ ├─ ◆ guitar        │ 音楽ハブ に属する弦楽器。      │    ● music ━━ ◆ guitar   │
│   ├─ • bass          │ 派生: acoustic / bass          │   ╭──╯        ┗━━┓       │
│   └─ · violin        │ ─── バックリンク (2件) ───     │   ● violin    ● electric │
│                      │   ← music  ...ギター...        │                          │
└──────────────────────┴────────────────────────────────┴──────────────────────────┘
```

- **左（階層ツリー）**：`▾` `├─` `└─` のガイド線、ノート数バッジ、現在地バー `▎` 付きでフォルダとノートを表示します。
- **中央（エディタ）**：`[[リンク]]` の括弧をスマートに隠す Live Preview と、末尾のクリック可能なバックリンク一覧を備えた編集画面です。
- **右（グラフビュー）**：角丸＋太線ハイライト罫線、または点字パターン (`⠀`〜`⣿`) でノートの繋がりを描画し、マウスドラッグやホイールで自在に動かせます。

## 2. 必要な環境とターミナル設定

- Emacs 27.1 以上（ターミナル版 `emacs -nw` ／ GUI 版どちらも対応）
- 数式を画像表示する場合のみ `latex` と `dvipng`（未導入でも美しい Unicode 数式へ自動変換されます）

### ターミナル版 Emacs でマウスを使うコツ
`M-x obsidian` を起動すると、自動的に `xterm-mouse-mode` と `mouse-wheel-mode` が有効になります。
- iTerm2 / WezTerm / Kitty / Alacritty / Ghostty / macOS 標準ターミナル / Windows Terminal では追加設定なしでクリック・ドラッグ・ホイールがすべて動作します。
- **`tmux` を使っている場合**は、`~/.tmux.conf` に次の1行を追加して再読み込み（`tmux source ~/.tmux.conf`）してください。これでパネル境界のドラッグ伸縮もそのまま通ります。

```tmux
set -g mouse on
```

## 3. インストールと起動

`init.el` に次を追加します。

```elisp
(add-to-list 'load-path "~/path/to/EMACS_OBSIDIAN")
(require 'obsidian)

;; 毎回同じ Vault を開く場合
(setq obsidian-vault-directory "~/Documents/MyVault")
```

設定反映後、次のコマンドでいつでも呼び出せます。

- `M-x obsidian`：3ペインのワークスペースを開く
- `M-x obsidian-daily-note`：今日のノート（`daily/YYYY-MM-DD.md`）をすぐに開く
- `M-x obsidian-find-note`：Vault 内のノートを検索して開く

**元の作業画面へ戻るには**：中央上部バーの **`[×終了]`** をクリックするか **`C-c o q`** を押すと、`M-x obsidian` を開く前のウィンドウ分割・バッファ状態へそのまま復帰します。コーディングの合間でも気軽に呼び出せます。

## 4. マウスによる領域変更と直感操作

1. **パネル幅をドラッグで変える**：パネル間の縦線 `│` をマウスで掴んで左右にドラッグすると、ツリー・エディタ・グラフの幅を自由に変更できます。変更後の比率は自動保存され、ターミナルウィンドウ自体のサイズを変えても比率が維持されます。
2. **ボタンクリックで幅調整・開閉する**：1文字幅の縦線 `│` を掴みにくい場合でも、上部ヘッダーバーの **`[◀]` `[▶]`** で4列ずつ伸縮でき、**`[×]`** でサイドパネルを閉じられます。閉じたパネルは中央バー左端・右端に現れる **`[▸ツリー]`** **`[グラフ◂]`** をクリックすると再表示されます。
3. **集中モード (`[集中]` / `C-c o z`)**：左右のサイドパネルを一括で隠して執筆に集中し、もう1クリックで3ペインに戻せます。

## 5. 左パネル：ビジュアル階層ツリー

- **`▎` と `◆`**：現在開いているノートを示します。本文中の `[[リンク]]` をクリックして別フォルダのノートへ飛んだ場合も、親フォルダが自動で展開されて現在地がハイライトされます。
- **`•`（色付きドット）**：現在開いているノートと直接リンクしている関連ノートです。ツリーを見るだけでも関連ファイルがひと目で分かります。
- **右クリックメニュー**：ファイルやフォルダの上で右クリックすると、新規作成・サブフォルダ作成・名前変更・並び替え・削除のメニューが開きます。
- **並び順とフィルタ**：上部の **`[名前順]`** をクリック（または `s` キー）すると **`[更新順]`**（最近編集した順）に切り替わります。**`[/絞込]`**（または `/` キー）でファイル名の部分一致フィルタをかけられます。
- **静かな自動スクロール**：長いノート名は普段は `…` で落ち着いて省略され、**カーソルを合わせた行だけ**がスムーズに横スクロールします。

## 6. 中央パネル：Live Preview とバックリンク

- **Live Preview (`[Live]` / `C-c o v`)**：`[[music|音楽ハブ]]` のようなリンクは普段はスッキリ `音楽ハブ` として表示され、**カーソルをその行に合わせた瞬間だけ `[[music|音楽ハブ]]` が現れて直接編集できます**。まだファイルが存在しないリンク先は別色で表示され、`C-x C-s` で保存すると自動作成されます。
- **`[[` インライン補完**：本文中で `[[` に続けて文字を打ち `TAB`（または `C-M-i`、Corfu 等）を押すと、Vault 内のノート名候補から補完され閉じ括弧 `]]` まで自動入力されます。
- **バックリンク一覧**：ノート下部に「このノートへリンクしている他のノートと文脈」が自動表示されます（オーバーレイ表示のため `.md` ファイル自体は一切汚しません）。`← ノート名` をクリックするとリンク元へジャンプできます。
- **リンク変更による自動リネーム**：既存リンクを1箇所だけ `[[old]]` → `[[new]]` に書き換えて保存するか、左ツリーで `R`（名前変更）を実行すると、ファイル本体のリネームと同時に Vault 内の全ノートにある被リンクも一括更新されます。

## 7. 右パネル：グラフビュー（罫線モード ＆ 点字モード）

- **線のスタイル切替 (`[線:罫線]` ↔ `[線:点字]` / `b` キー)**：
  - **角丸＋太線ハイライト罫線モード（既定）**：背景の接続は角丸 `╭ ╮ ╰ ╯` で控えめに、現在ノートから伸びる直接リンクは太線 `━ ┃ ┏ ┓` とアクセントカラーで鮮明に描きます。
  - **点字パターン高精細モード**：点字文字 (`⠀`〜`⣿`) の2×4ドットを使い、ターミナル上とは思えない滑らかな斜線グラフを描画します。
- **表示範囲の切替 (`[範囲:...]` / `f` キー)**：
  - `自動`：選択中のフォルダを表示（Vault直下にノートがない場合は自動的に Vault 全体を表示するため、起動直後からグラフを楽しめます）
  - `2-hop`：現在ノートから2ステップ以内の関連ノートを**別フォルダも含めて横断表示**
  - `フォルダ`：現在のフォルダ内のみ表示
  - `全体`：Vault 内のすべてのノートを表示
- **マウスドラッグ＆ホイールズーム**：グラフ上をマウスで掴んでドラッグすると表示位置を移動（パン）でき、ホイール回転や `[-]` `[+]` ボタンで拡大・縮小できます。
- **キーボードでのノード巡回**：マウスを使わない時も `TAB` / `S-TAB` で接続先ノード（`◈`）を順番にハイライトし、`RET` でそのまま開けます。

## 8. Git 自動同期とカスタマイズ

Vault（またはそのサブフォルダ）が Git リポジトリの場合、保存時の自動 commit / rebase pull / push と60秒ごとのバックグラウンド pull が動作します（未保存の編集中は上書き防止のため自動保留されます）。

設定は `M-x customize-group RET obsidian RET` からいつでも変更できます。
