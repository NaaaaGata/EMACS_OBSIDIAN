# EMACS_OBSIDIAN

ターミナル版 Emacs (`emacs -nw`) や GUI 版 Emacs の中で、Obsidian のようなツリー表示・グラフビュー・相互リンク執筆を楽しめるノート環境パッケージです。`M-x obsidian` の1コマンドで、左にビジュアル階層ツリー、中央に Live Preview 対応エディタ、右にドラッグ移動＆ズーム可能なリンクグラフを開きます。

初めて使う方は、[日本語ユーザーガイド](docs/USER_GUIDE_JA.md)を参照してください。

## 主な機能

- **ターミナル版 Emacs でもフルマウス対応** (`xterm-mouse-mode` 自動有効化)
  - パネル境界線 `│` の左右ドラッグによる自由な領域幅リサイズ（比率自動保存）
  - 各パネル上部のクリック可能なヘッダーツールバー (`[+新規]` `[今日]` `[検索]` `[線:罫線/点字]` `[◀][▶]` `[×]` など)
  - 左ツリーの右クリック操作メニュー（作成・名前変更・並替・削除）
  - 右グラフのマウスドラッグ移動（グラブ・パン）とホイール拡大・縮小
- **標準フォントで列ズレしない美しいビジュアルツリー**
  - `▾` `├─` `└─` `│` の階層ガイド線とフォルダ内ノート数バッジ
  - 現在開いているノートの左端バー `▎` ＋ `◆` 強調表示＆自動展開追従 (Auto-reveal)
  - 現在ノートとリンク接続されたノートをツリー上でも `•` 色付きドットで可視化
  - 名前順／更新日時順ソート切替 (`s`)、インクリメンタル絞り込み (`/`)、カーソル行のみ静かにスクロールするスマート・マーキー
- **2種類の描画モードを持つインタラクティブ・グラフビュー**
  - **角丸＋太線ハイライト罫線モード（既定）**: 背景エッジを角丸 `╭ ╮ ╰ ╯` で柔らかく描き、現在ノートの接続だけを太線 `━ ┃ ┏ ┓` で鮮やかに強調
  - **点字パターン高精細モード**: 上部 `[線:点字]` ボタン（または `b` キー）1クリックで、1文字2×4ドットの点字サブピクセル斜線 (`⠀`〜`⣿`) へ瞬時に切替
  - **スコープ切替**: `自動` / `2-hop ローカル近傍（フォルダ横断）` / `フォルダ単体` / `Vault全体` をワンクリック切替
  - **`TAB` ノード巡回**: キーボードだけでも接続先ノードを次々フォーカスして `RET` でジャンプ可能
- **Obsidian 風 Live Preview ＆ 快適執筆ワークフロー**
  - `[[note|表示名]]` の括弧を普段はスマートに隠し、カーソル行だけ生テキストを表示する Live Preview (`[Live]` / `C-c o v`)
  - 本文中で `[[` と打つだけでノート候補を補完 (`completion-at-point`)
  - ノート下部にファイルを汚さないクリック可能な**バックリンク（被参照一覧）**を自動表示
  - **デイリーノート** (`C-c o d` / `[今日]`)、**ノート高速検索** (`C-c o p` / `[検索]`)、**元の作業画面へのワンタッチ復帰** (`C-c o q` / `[×終了]`)
  - `$...$` と `$$...$$` の LaTeX 画像／Unicode 数式プレビュー
  - Git管理された Vault での自動 commit / rebase pull / push 同期

## インストール

このリポジトリを任意の場所へ置き、`init.el` に次を追加します。

```elisp
(add-to-list 'load-path "/path/to/EMACS_OBSIDIAN")
(require 'obsidian)

;; 毎回フォルダを尋ねずに起動する場合
(setq obsidian-vault-directory "~/Documents/MyVault")
```

設定を評価するか Emacs を再起動し、`M-x obsidian`（または `M-x obsidian-daily-note`）を実行してください。

> **ターミナル（tmux）利用時のヒント**: iTerm2 / WezTerm / Kitty / Alacritty / Ghostty / Windows Terminal 等ではそのままマウス操作が動きます。`tmux` 内で使う場合は `~/.tmux.conf` に `set -g mouse on` を入れておくとドラッグリサイズやホイール操作が透過されます。

## 基本操作

### マウスでの直感操作（全ペイン共通）

| 操作 | 内容 |
|---|---|
| パネル間の縦線 `│` を左右ドラッグ | 左ツリー・中央エディタ・右グラフの幅を自由に変更（自動保存） |
| 上部バーの `[◀]` `[▶]` / `[×]` | パネル幅の段階変更 ／ サイドパネルを隠す（`[▸ツリー]` `[グラフ◂]` で再表示） |
| 左ツリーを左クリック / 右クリック | ノートを開く・フォルダ開閉 ／ 右クリックメニュー（新規・改名・削除・並替） |
| 右グラフをドラッグ / ホイール回転 | マップの表示位置を移動（パン） ／ 拡大・縮小（ズーム） |
| 右グラフ上部 `[範囲:...]` / `[線:...]` | `2-hop` や全体表示への切替 ／ **罫線モード ↔ 点字モード**の切替 |

### 左：階層ツリー

| 操作 | 内容 |
|---|---|
| 左クリック / `RET` | フォルダを開閉、またはノートを中央に開く |
| 右クリック | コンテキストメニュー（開く・新規ノート・新規フォルダ・名前変更・削除） |
| `↑` / `↓` または `k` / `j` | 前後のフォルダ・ノートへ移動 |
| `TAB` / `→` / `←` | フォルダを展開 ／ 折りたたみ（ファイル上での `←` は親フォルダへ移動） |
| `z` | 全フォルダを一括展開 ／ 一括折りたたみ |
| `n` / `+` | 新規ノート作成 ／ 新規サブフォルダ作成 |
| `R` | カーソル位置のノート名・フォルダ名を変更（Vault内の被リンクも自動更新） |
| `s` / `/` | 並び順切替（名前順 ↔ 更新日時順） ／ ノート名の絞り込みフィルタ |
| `Esc` | 確認後にノートをゴミ箱へ移動 |
| `<` / `>` / `q` | 左パネルを縮小 ／ 拡大 ／ 隠す |

### 中央：Markdown 編集（Live Preview 対応）

| 操作 | 内容 |
|---|---|
| `[[` + `TAB` (`C-M-i`) | カーソル位置でノート名をインライン補完 |
| 左クリック / `M-RET` / `C-c o f` | Wiki リンクを開く（未作成なら作成確認） |
| `C-c o n` / `C-c o d` / `C-c o p` | 新規ノート ／ 今日のデイリーノート ／ Vault内ノート検索 |
| `C-c o l` / `C-c o b` | Wiki リンク挿入 ／ 直前のノートへ戻る |
| `C-c o v` / `C-c o k` / `C-c o t` | Live Preview 切替 ／ バックリンク表示切替 ／ LaTeX 数式プレビュー切替 |
| `C-c o z` / `C-c o 1` / `C-c o 3` | 集中モード（左右一括開閉） ／ 左ツリー開閉 ／ 右グラフ開閉 |
| `C-c o q` | Obsidian を閉じて起動前のウィンドウ構成へ戻る |
| `C-x C-s` | 保存（未作成リンク先の自動作成・単一リンク変更時の自動リネーム・Git同期） |

### 右：グラフビュー

| 操作 | 内容 |
|---|---|
| マウスドラッグ / 矢印 / `h j k l` | 仮想グラフ上のカメラを移動（パン） |
| ホイール回転 / `+` / `-` | グラフの拡大・縮小（ズーム） |
| 左クリック / `TAB` → `RET` | クリックしたノートを開く ／ `TAB` で接続ノードを巡回選択して `RET` で開く |
| `b` | **角丸＋太線罫線モード** と **点字高精細モード (`⠀`〜`⣿`)** を切替 |
| `f` | 表示範囲を切替（`自動` → `2-hop近傍` → `フォルダ` → `Vault全体`） |
| `0` / `g` | 現在ノートを中央へ戻す ／ 再描画 |
| `<` / `>` / `q` | 右パネルを縮小 ／ 拡大 ／ 隠す |

## 主なカスタマイズ変数

`M-x customize-group RET obsidian RET` から設定できます。

- `obsidian-vault-directory` — 既定の Vault パス
- `obsidian-enable-terminal-mouse` — ターミナル起動時のマウス自動有効化（既定 `t`）
- `obsidian-show-header-buttons` — 各ペイン上部のクリックツールバー表示（既定 `t`）
- `obsidian-tree-sort-method` — ツリー初期並び順（`'name` または `'mtime`）
- `obsidian-tree-marquee-only-current-line` — カーソル行のみ横スクロール（既定 `t`）
- `obsidian-graph-edge-style` — グラフ線スタイル（`'box` 角丸太線 または `'braille` 点字）
- `obsidian-graph-scope-mode` — グラフ初期範囲（`'auto`, `'local`, `'folder`, `'global`）
- `obsidian-live-preview` — `[[リンク]]` ブラケットの自動隠蔽（既定 `t`）
- `obsidian-show-backlinks` — ノート末尾のバックリンク表示（既定 `t`）
- `obsidian-daily-folder` / `obsidian-daily-note-format` — デイリーノートの保存先と書式
